Domain Model Description
DataInsight AI’s domain model represents the core entities required to ingest multimodal data, process it, and generate explainable insights. A DataAsset is the main abstract entity capturing uploaded or ingested content, specialized into DocumentAsset, ImageAsset, AudioAsset, and VideoAsset. Assets may be provided by an ExternalDataSource such as an API or repository. Each DataAsset produces a ProcessingContext that contains ExtractedText, representing the normalized text used for downstream analysis. Users initiate AI processing through a TaskRequest, which generates a TaskResult containing the system’s answer and confidence score. To ensure transparency, TaskResult is linked to EvidenceRef objects that point back to the original DataAsset and location within that asset (e.g., page number or timestamp). SearchQuery and SearchHit entities support semantic querying by linking user queries to matched assets.
