# Sample Test Files

These 3 audio files are from **The Economist** (January 2024 audio edition) and are provided for testing the DataInsight AI audio transcription and AI analysis pipeline.

## Files

| File | Topic | Size |
|------|-------|------|
| `economist_finance_buttonwood.mp3` | Financial markets column | ~2.3 MB |
| `economist_finance_international_commerce.mp3` | International trade & finance | ~3.9 MB |
| `economist_business_technology.mp3` | Business & technology | ~5.5 MB |

## How to Test

1. Open the DataInsight AI app
2. Click **From Computer** and upload any of these MP3 files
3. Click **Prepare for AI** — this extracts the speech via Whisper and indexes it
4. Once status shows **INDEXED**, ask questions like:
   - *"What is the main argument?"*
   - *"Summarize this audio"*
   - *"What economic trends are discussed?"*
   - *"What companies or figures are mentioned?"*
